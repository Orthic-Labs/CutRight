# Cross-Brand Rules

- **Never mix brand assets** — each brand has its own fonts, colors, and tone
- **Never fabricate** quotes, statistics, testimonials, or personal stories for ANY brand
- When generating content, always specify which brand it's for and apply that brand's visual system
- Run `/marketing context` when a venture lacks current product/audience/positioning context

## Motion Principles (All Brands, Especially DD)

- **Slow is premium** — favour eased-in reveals over snappy transitions
- **Precision over flash** — every element should feel intentional
- **Restraint** — white space (or dark space) is part of the design
- **Physics feel real** — use `spring({ stiffness: 60, damping: 14 })` as default for most reveals
- Copper accents animate last, as a finishing detail (like a signature)
