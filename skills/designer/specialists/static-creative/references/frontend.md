# Routing stub — frontend design and review

**For frontend visual QA, critique, polish, strict visual/UX gates, and micro-interaction review, use `cutright://skill/qa {"mode":"visual_review"}`.**

**For building new marketing sites, landing pages, or non-app web pages from scratch, use `cutright://skill/designer`.**

This file is a routing stub only. The canonical instructions for:

- Visual/UX audit gates (task cognition, hierarchy, Baymard/ecommerce, Gestalt, craft, Peak-End) → `cutright://skill/qa {"mode":"visual_review"}`
- Accessibility, WCAG AA gates, micro-interaction requirements → `cutright://skill/qa {"mode":"visual_review"}`
- Website signature mechanism, anti-template gates, page workflow → `cutright://skill/designer`
- Production frontend component code (React + Tailwind, distinctive aesthetics) → `cutright://skill/designer`

> `cutright://skill/designer static` does not own interactive frontend work. If you landed here from a `cutright://skill/designer static` invocation with a
> web page or frontend review request, stop and route to the correct skill above.
